# nopixel V Stream Recap (xQc POV)

Interactive Day 1 & Day 2 stream recap, timeline tracker, and VOD synchronization hub for NoPixel 5.0 (xQc / Jean Paul POV).

## Overview

- **Live URL**: [npvxqcpov.vercel.app](https://npvxqcpov.vercel.app/)
- **Author Credits**: Live stream timestamps compiled by u/HurricaneRein on r/xqcow.
- **Features**:
  - Interactive multi-day timeline with 150+ timestamped events
  - 1-Click ad-free in-app Kick stream player (HLS with direct timestamp seeking)
  - Kick & Twitch VOD synchronization links
  - Extras Intel: Character background lore, stream telemetry, economic stats, and cast list
  - Search & category filtering (Crime, Police Chases, Jobs, Medical, Lore, Crypto)
  - Bookmarking and direct moment link sharing
  - Privacy-friendly visitor analytics

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide Icons, Hls.js
- **Deployment**: Vercel (Edge CDN)
- **Local Server**: Node.js, Express 5
- **Scraper / Sync**: Python 3 (Reddit RSS & post scraper)
